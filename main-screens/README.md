# Экраны главной (копии TSX)

Три файла дизайна главных экранов — копии из проекта, без изменений:

| Файл | Что это | Оригинал |
|---|---|---|
| parent-index.tsx | главная родителя | mobile/src/app/parent/(tabs)/index.tsx |
| child-index.tsx | главная ребёнка | mobile/src/app/child/(tabs)/index.tsx |
| CardPeek.tsx | карта: свайп, раскрытие, баланс на карте, CVV/PIN | mobile/src/ui/CardPeek.tsx |

Правки делаются только в оригиналах в mobile/src — эти файлы не участвуют в сборке.
