# TSX-файлы дизайна (копии)

Это **копии** исходников для быстрого просмотра дизайна. Единственный источник истины — `mobile/src/`.
Править здесь ничего не нужно: правки делаются в `mobile/src/**`, эти файлы не участвуют в сборке.

Что внутри:

- `mobile/src/app/...` — экраны: главные родителя и ребёнка, игра «Недельный бюджет», копилки,
  задания, профиль, счета, права, продукты, настройки, вся регистрация (телефон → код → ФИО+ИН →
  ребёнок → согласия → оплата пакета → выбор карты → чек).
- `mobile/src/ui/...` — все компоненты дизайн-системы: `CardPeek` (карта), `Glow` (свечения),
  `PaymentBrand` (Visa/Mastercard/Белкарт/UnionPay), `SlideToConfirm` (слайдеры), `GlassCard`,
  `ProgressRing`, `SpendCard`, `AiInsights`, `ConfirmCodeModal`, примитивы.
- `mobile/src/theme/...` — палитра (тёмная/светлая), токены (радиусы, отступы, размеры), шрифты TikTok Sans + Inter.

HTML-макеты дизайнера — в `design/mockups/`.
