# Как изменить тесты по финансовой грамотности

Тесты (квизы) Moby Family лежат **не в базе данных и не в приложении**, а прямо в коде сервера. Это значит: правишь файл – тесты обновляются после перезапуска сервера, без миграций и без релиза мобильного приложения.

---

## 1. Где лежит контент

```
server/src/quizzes.ts
```

Файл экспортирует два интерфейса и один массив:

| Экспорт | Что это |
| --- | --- |
| `QuizQuestion` | один вопрос теста |
| `Quiz` | один тест целиком |
| `QUIZZES` | массив всех тестов – именно его читает сервер |

### Структура `QuizQuestion`

```ts
export interface QuizQuestion {
  id: string;                             // q1, q2, q3...
  text: { ru: string; be: string };       // текст вопроса
  options: { ru: string[]; be: string[] }; // 3–4 варианта, ru и be строго одинаковой длины
  correct: number;                        // индекс правильного варианта, нумерация С НУЛЯ
  why: { ru: string; be: string };        // объяснение после ответа, 1–2 предложения
}
```

### Структура `Quiz`

```ts
export interface Quiz {
  id: string;                              // латиница через дефис: c-... для детей, p-... для родителей
  audience: "child" | "parent";            // кому показывать
  kind: "quiz";                            // всегда "quiz"
  points: number;                          // награда монетами: детские 40–80, родительские 100–200
  title: { ru: string; be: string };
  desc: { ru: string; be: string };
  questions: QuizQuestion[];               // 4–5 вопросов
}
```

### Пример готового вопроса

```ts
{
  id: "q2",
  text: {
    ru: "Что делать, если во время покупки пришёл код из СМС?",
    be: "Што рабіць, калі падчас пакупкі прыйшоў код з SMS?",
  },
  options: {
    ru: [
      "Продиктовать его человеку, который позвонил и назвался сотрудником банка",
      "Отправить его в общий чат класса",
      "Записать на карточке и носить с собой",
      "Никому не сообщать: это код подтверждения именно твоей операции",
    ],
    be: [
      "Прадыктаваць яго чалавеку, які пазваніў і прадставіўся супрацоўнікам банка",
      "Адправіць яго ў агульны чат класа",
      "Запісаць на картцы і насіць з сабой",
      "Нікому не паведамляць: гэта код пацверджання менавіта тваёй аперацыі",
    ],
  },
  correct: 3, // правильный – последний вариант
  why: {
    ru: "Код из СМС подтверждает именно твою операцию. Если его у тебя просят – это мошенники.",
    be: "Код з SMS пацвярджае менавіта тваю аперацыю. Калі яго ў цябе просяць – гэта махляры.",
  },
},
```

## 2. Как добавить новый тест

1. Открой `server/src/quizzes.ts` и добавь новый объект в конец массива `QUIZZES`.
2. Выбери **id**:
   - префикс `c-` – детский тест (например `c-save-1`);
   - префикс `p-` – родительский (например `p-budget-2`);
   - только латиница, слова через дефис, в конце – номер версии.
3. Укажи `audience`: `"child"` или `"parent"`. `kind` всегда `"quiz"`.
4. Задай `points` (см. раздел 5).
5. Заполни `title` и `desc` на двух языках.
6. Добавь 4–5 вопросов в `questions`.
7. Перезапусти сервер (раздел 6) и проверь тест в приложении.

Шаблон нового теста:

```ts
{
  id: "c-save-1",
  audience: "child",
  kind: "quiz",
  points: 50,
  title: { ru: "Заголовок", be: "Загаловак" },
  desc: { ru: "Короткое описание", be: "Кароткае апісанне" },
  questions: [
    {
      id: "q1",
      text: { ru: "Вопрос?", be: "Пытанне?" },
      options: {
        ru: ["Вариант 1", "Вариант 2", "Вариант 3"],
        be: ["Варыянт 1", "Варыянт 2", "Варыянт 3"],
      },
      correct: 1,
      why: { ru: "Объяснение.", be: "Тлумачэнне." },
    },
    // ... ещё 3–4 вопроса
  ],
},
```

## 3. Как изменить или удалить вопрос

- **Изменить текст варианта** – правь строку в `options.ru` и соответствующую строку в `options.be`. Следи, чтобы массивы `ru` и `be` остались одинаковой длины и порядок вариантов совпадал.
- **Сменить правильный ответ** – поменяй `correct` на новый индекс (нумерация с **0**: `0` – первый вариант, `1` – второй и так далее).
- **Удалить вопрос** – удали объект вопроса целиком. Не забудь: если после удаления осталось меньше 4 вопросов, добавь новый или удали тест из `QUIZZES`.
- **Удалить тест** – удали объект теста целиком из массива `QUIZZES`.

> Важно: у каждого вопроса должен быть уникальный `id` внутри своего теста (`q1`, `q2`, `q3`...). Переиспользовать один `q2` дважды в одном тесте нельзя.

---

## 4. Чего НЕЛЬЗЯ делать после релиза

```
id теста и id вопроса менять нельзя, если тест уже ушёл в прод.
```

Прогресс детей хранится в таблице `quest_progress` по ключу `quest_id`. Если переименовать тест `c-card-1` в `c-card-01`, сервер посчитает, что ребёнок этот тест не проходил, и **прогресс потеряется**.

Если нужно «переиздать» тест с новым содержанием – **не переименовывай старый id**, а создай новый:
```ts
{ id: "c-card-2", ... }  // новая версия рядом со старой
```

Аналогично, не удаляй тест, который уже проходили дети: у них навсегда потеряется отметка о выполнении. Лучше убрать тест из выдачи позже, но не удалять его id из базы.

---

## 5. Баллы и монеты

- `points` детского теста – **40–80 монет** (небольшая награда, чтобы ребёнок охотнее проходил новые тесты).
- `points` родительского теста – **100–200 монет** (для родительского магазина наград).
- За каждый тест награда начисляется **один раз** – повторное прохождение монет не добавляет.
- Чем длиннее и сложнее тест, тем выше `points` внутри своего диапазона.
- Если хочешь давать много монет, лучше сделать несколько коротких тестов, чем один длинный: так награда приходит чаще и интерес не теряется.

---

## 6. Как проверить изменения

1. Останови и запусти сервер заново:
   ```bash
   sudo systemctl restart moby-api
   ```
2. Тесты подтягиваются **автоматически** при старте сервера из файла `server/src/quizzes.ts`.
3. **Миграции не нужны**, базу трогать не надо – каталог лежит в коде.
4. Открой приложение и убедись, что новый тест появился в списке, вопросы отображаются на двух языках, а награда начисляется один раз.

Перед перезапуском полезно проверить, что файл не сломан:

```bash
cd server && npx tsc --noEmit
```

Если ошибок нет – файл валиден. Ошибки в других файлах сервера не связаны с контентом тестов.

---

## 7. Как выложить на прод

1. Убедись, что `npx tsc --noEmit` не показывает ошибок в `quizzes.ts`.
2. Задеплой сервер по инструкции из `docs/DEPLOY.md`.
3. После выкладки перезапусти сервис: `sudo systemctl restart moby-api`.
4. Проверь тесты в приложении.

Готово: приложение выпускать не нужно – новые тесты придут с сервера.

---

## 8. Безопасность: правильные ответы не уходят в приложение

Поле `correct` **хранится только на сервере** и в мобильное приложение не отправляется: клиент получает вопрос, варианты ответа и текст объяснения `why`, а проверку ответа делает сервер.

Это значит:

- индекс правильного ответа нельзя подсмотреть в приложении или подделать с телефона;
- тест нельзя «пройти», просто зная порядок правильных ответов;
- `why` приходит клиенту сразу (без него не показать объяснение), но он ничего не выдаёт: правильность ответа всё равно определяет сервер и начисляет монеты только за верный ответ.

Никогда не переносить логику проверки ответа в приложение и не отдавать `correct` в API.

---

## 9. Языки и тон

- Каждый текст дублируется на русском (`ru`) и белорусском (`be`) – оба поля обязательны.
- Белорусский – живой литературный, без транслита и без русского текста.
- Банковские термины простые и правильные: *карта*, *рахунак*, *плацеж*, *ліміт*, *кішэнныя грошы*.
- Тон дружелюбный, как у банковского приложения для семьи: без сложных терминов, без политики, без запугивания.
- Факты должны быть верными: если сомневаешься в банковском факте – проверь у аналитиков или в `docs/ARCHITECTURE.md` перед публикацией.
