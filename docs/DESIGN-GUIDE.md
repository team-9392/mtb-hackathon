# Как менять дизайн и тексты – простая инструкция

Эта инструкция для того, кто открыл проект впервые. Ничего знать про React Native не нужно:
всё, что чаще всего меняют (цвета, надписи, размеры, иконки), лежит в четырёх файлах.
Меняешь строку – сохраняешь – смотришь на телефоне. Приложение обновляется само.

---

## 1. Карта: где что лежит

| Что хочу поменять | Файл |
|---|---|
| Все цвета | `mobile/src/theme/tokens.ts` |
| Тексты на русском | `mobile/src/i18n/ru.ts` |
| Тексты на белорусском | `mobile/src/i18n/be.ts` |
| Отступы, скругления, тени | `mobile/src/theme/tokens.ts` (там же) |
| Кнопки, карточки, значки | `mobile/src/ui/` |
| Сам экран целиком | `mobile/src/app/…` (один файл = один экран) |
| Правила: лимиты, запрет 18+, вклад | `server/src/rules.ts` |

Правило проекта: цвета никогда не пишутся в экранах «руками». Экран берёт цвет из
`tokens.ts`. Поэтому поменял там одну строку – поменялось везде.

---

## 2. Как поменять цвет

1. Открой `mobile/src/theme/tokens.ts`.
2. Найди `export const palette = {` – это список всех цветов.
3. Замени значение справа от двоеточия. Значение – HEX-код вида `#3B5BFD`.

```ts
export const palette = {
  primary: "#3B5BFD",   // ← главный цвет кнопок и ссылок
  child: "#FF7A3D",     // ← цвет детской части
  mint: "#12B886",      // ← «всё хорошо»: прогресс, успех
  danger: "#E5484D",    // ← ошибки и запреты
  bg: "#F4F5FA",        // ← фон всех экранов
  surface: "#FFFFFF",   // ← фон карточек
  ink: "#0F172A",       // ← основной текст
  muted: "#667085",     // ← подписи помельче
} as const;
```

Что чаще всего меняют:

| Что | Ключ | Сейчас |
|---|---|---|
| Главный цвет (кнопки, активные вкладки) | `primary` | `#3B5BFD` синий |
| Детская часть | `child` | `#FF7A3D` оранжевый |
| Фон приложения | `bg` | `#F4F5FA` светло-серый |
| Карточки | `surface` | `#FFFFFF` белый |
| Текст | `ink` | `#0F172A` почти чёрный |

Если меняешь общий вид – обычно достаточно поменять `primary` и `bg`, остальное подстроится.

**Градиенты** (цветные карточки сверху) – там же, ниже:

```ts
export const gradients = {
  parent: ["#3B5BFD", "#6C4DF6"],   // карточка родителя
  child: ["#FF9A3D", "#FF5E7E"],    // карточка ребёнка
};
```

Цвета в квадратных скобках – от какого к какому переливается. Можно поставить сколько угодно
цветов через запятую, главное чтобы в кавычках.

## 3. Как поменять текст

Тексты лежат отдельно от экранов, в двух словарях. Ключ слева – адрес текста, справа – сам текст.

1. Открой `mobile/src/i18n/ru.ts` – это русский.
2. Найди строку по тексту, который видишь на экране (например `"auth.phoneTitle"`).
3. Меняй только то, что справа в кавычках.
4. **То же самое обязательно сделай в `be.ts`** – там белорусский.

```ts
// ru.ts
"auth.phoneTitle": "Вход в Moby Family",
"auth.sendCode": "Получить код",

// be.ts – тот же ключ, другой текст
"auth.phoneTitle": "Уваход у Moby Family",
"auth.sendCode": "Атрымаць код",
```

Почему в обоих файлах: если ключ есть в русском, но забыт в белорусском, проверка типов
сразу скажет об этом и подсветит ошибку. Так перевод не теряется.

Если в тексте нужна подстановка (например номер телефона):

```ts
"auth.codeSubtitle": "Код отправлен на {phone}",
```

В фигурных скобках – имя переменной, менять его нельзя, а сам текст вокруг – можно.

## 4. Как поменять размеры, отступы, скругления, тень

Всё в том же `tokens.ts`:

```ts
export const spacing = { xs: 4, sm: 8, md: 12, lg: 16, xl: 20, xxl: 28 };  // отступы
export const radius  = { sm: 10, md: 14, lg: 20, xl: 28, pill: 999 };     // скругления углов
export const font    = { h1: 30, h2: 24, h3: 19, title: 17, body: 15.5, small: 13.5, tiny: 11.5 };
```

- Хочешь карточки «круглее» – увеличь `radius.lg`.
- Хочешь крупнее заголовки – увеличь `font.h1` и `font.h2`.
- Хочешь больше воздуха – увеличь `spacing.lg` и `spacing.xl`.

Меняешь число – меняется на всех экранах сразу.

## 5. Как поменять иконку

Иконки берутся из набора Ionicons. В коде имя пишется так:

```tsx
<Ionicons name="home-outline" size={22} color={palette.primary} />
```

Чтобы поменять: замени `home-outline` на другое имя из набора
(список с картинками: https://ionic.io/ionicons – раздел Ionicons).
`size` – размер, `color` – цвет (тоже из `tokens.ts`).

Важно: имя должно существовать. Если опечататься, проверка типов подскажет похожее имя.

## 6. Как поменять порядок экранов и вкладок

Каждый файл в `mobile/src/app/` – это экран, а папка – это путь к нему.
Ничего регистрировать не нужно, путь = расположение файла.

| Файл | Что открывается |
|---|---|
| `src/app/index.tsx` | первый экран: выбор роли |
| `src/app/auth/phone.tsx` | вход по номеру телефона |
| `src/app/auth/code.tsx` | ввод кода из SMS |
| `src/app/parent/(tabs)/index.tsx` | вкладка «Обзор» у родителя |
| `src/app/child/(tabs)/index.tsx` | главный экран ребёнка |

Вкладки нижнего меню описаны в файле `_layout.tsx` соответствующей папки:

```tsx
<Tabs.Screen name="index"  options={{ title: t("ov.tab") }} />
<Tabs.Screen name="rights" options={{ title: t("rg.tab") }} />
```

- Чтобы **переименовать вкладку** – поменяй подпись в `ru.ts`/`be.ts` по ключу из `t(...)`.
- Чтобы **поменять порядок** – переставь строки `<Tabs.Screen …>` местами.
- Чтобы **спрятать вкладку** – добавь `options={{ href: null }}`.

## 7. Как посмотреть, что получилось

1. На компьютере: `cd mobile && npx expo start`.
2. Телефон: приложение **Expo Go**, отсканировать QR.
3. Меняешь файл → сохраняешь → экран на телефоне обновляется сам за секунду.

Если телефонов рядом нет – можно открыть в браузере: `npx expo start --web`
(выглядит похоже, но это не телефон).

## 8. Как проверить, что ничего не сломал

Перед тем как отдать кому-то, прогони три команды в папке `mobile`:

```bash
npm run typecheck   # ищет опечатки и забытые переводы
npm run lint        # ищет мусор в коде
npx expo export --platform android   # проверяет, что приложение вообще собирается
```

Если все три прошли – можно показывать.

## 9. Частые ошибки и что делать

| Что видишь | Причина | Что делать |
|---|---|---|
| `Property "auth.sendCode" does not exist` | В `ru.ts` есть ключ, а в `be.ts` нет | Добавь тот же ключ в `be.ts` |
| Текст на экране не поменялся | Правил один словарь, а язык переключён на другой | Проверь, какой язык выбран на экране входа, и правь оба файла |
| Цвет поменялся не везде | В каком-то экране цвет вписан руками | Найди HEX-код поиском по папке `src` и замени на значение из `tokens.ts` |
| Ошибка про иконку | Имя иконки написано неверно | Возьми точное имя из набора Ionicons |
| Экран пропал | Файл переименовали или положили не в ту папку | Путь экрана = путь файла: `src/app/parent/limits.tsx` → `/parent/limits` |
| Приложение пишет «Сервер недоступен» | Нет интернета или API лежит | Приложение работает и без сервера: очисти `apiUrl` в `mobile/app.json` – включится демо-режим |

## 10. Правила «тихого» дизайна (чеклист)

Мы договорились делать спокойный банк без визуального шума. Правя экран, проверь по списку:

1. **Один акцентный цвет на экран.** Не делай две яркие кнопки рядом.
2. **Иконка не получает цветную плашку «просто так»** – только если несёт смысл.
3. **Одна главная кнопка на экран**, остальные – текстовые ссылки.
4. **Один градиент на экран** (верхняя карточка), остальное – плоские поверхности.
5. **Не больше двух фоновых поверхностей**: фон приложения и карточка.
6. **Вес шрифта не жирнее 700**, суммы – крупно и заметно, подписи – мелко и серо.
7. **Никаких эмодзи** во взрослой части приложения; в детской – только награды и цель.
8. **Пустой экран** = иконка, одна строка, одна кнопка.

## 11. Если нужно поменять не вид, а правила

Бизнес-правила живут на сервере, в `server/src/rules.ts`:

```ts
export const HARD_BLOCKED_CATEGORIES: string[] = ["gambling", "adult"];   // запрещено всегда
export function productsFor(bracket) { … }        // какие продукты доступны 7–13 и 14–17
export function defaultLimits(bracket) { … }      // лимиты по умолчанию
```

После правки:

```bash
cd server && npm test        # 8 проверок правил
```

Затем выложить на сервер (см. `docs/DEPLOY.md`, раздел «Обновление»).
Ничего менять в приложении при этом не нужно – оно спросит сервер.
