# Логотипы партнёров

Сюда кладём PNG-логотипы партнёров (рекомендуется 256×256, прозрачный фон).
Имя файла указывается в `server/src/rewards.ts` → `partner.logo`.

Пример: `cafe.png` → в награде `partner: { name: "Кофейня «Верас»", logo: "cafe.png" }`.

Сервер раздаёт файлы по адресу `/moby/partners/<имя файла>` — приложение показывает их
без пересборки: достаточно положить файл и перезапустить сервис (или даже без перезапуска).

Форматы: png, jpg, jpeg, webp, svg.
Если файла нет — приложение покажет нейтральную иконку, ошибки не будет.
