# Moby Family — мобильное приложение (Expo / React Native)

Демо-прототип семейного банкинга для хакатона: **пакет «Фэмили»** — родитель оформляет и управляет,
ребёнок пользуется картой в рамках выданных прав.

Прототип запускается **с реальных телефонов iPhone и Android** через Expo Go.

## Быстрый старт (2 телефона)

```bash
cd mobile
npm install
npx expo start --tunnel
```

1. Установите **Expo Go** из App Store / Google Play на iPhone и на Android.
2. Отсканируйте QR из терминала первым телефоном, затем вторым.
3. На первом выберите **«Я родитель»**, пройдите путь оформления.
4. На втором выберите **«Я ребёнок»** — экран станет доступен после того, как родитель выдаст доступ.

`--tunnel` нужен, потому что Wi-Fi на площадке часто изолирует устройства друг от друга.
Если туннель не поднимается — используйте офлайн-режим: демо-панель (шестерёнка → «Демо-панель»)
позволяет прыгнуть на любой шаг сценария на одном телефоне.

## Проверки

```bash
npm test                                    # проверки бизнес-логики (10 сценариев)
npm run typecheck                           # tsc --noEmit
npm run lint                                # expo lint
npx expo export --platform android          # проверка, что бандл собирается
```

## Структура

```
src/
  app/                  маршруты Expo Router (каждый файл — экран)
    index.tsx           выбор роли (родитель / ребёнок)
    demo.tsx            демо-панель: прыжок по шагам, сброс, язык, роль
    parent/             путь родителя
      offer, child-profile, consents, issue, access
      (tabs)/           обзор, права, лимиты, прогресс
    child/              путь ребёнка
      (tabs)/           мой Moby, копилка, квесты, профиль
      request, blocked  запрос доступа, «почему недоступно»
  store/                типы, mock-данные, движок прав (7–13 / 14–17), провайдер
  i18n/                 русский и белорусский словари (ru.ts / be.ts)
  ui/                   кнопки, карточки, тосты, hero-карточки, шапка экрана
  theme/tokens.ts       палитра, отступы, радиусы, тени
  lib/format.ts         формат сумм и дат
```

## Что уже работает

- Путь родителя целиком: оффер → возраст ребёнка (7–13 / 14–17) → согласия (включая 99-З) →
  выпуск карты → выдача доступа ребёнку → права → лимиты → обзор с операциями и блокировкой карты.
- Путь ребёнка: баланс, карманные, копилка с целью, квесты и уроки с наградами,
  запрос доступа к продукту, экран «почему недоступно».
- Жёсткие правила ядра: азартные игры и категории 18+ заблокированы и не снимаются родителем.
- Русский и белорусский интерфейс, переключение на экране выбора роли и в демо-панели.
